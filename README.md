# Object-Relational-Mapping(ORM) E-commerce-Back-End

# Description
## A back end for an e-commerce site. That will take take a working Express.js API and configure it to use Sequelize to interact with a PostgreSQL database 

# Usage
## A fuctional back end data base for a e-commerce website that uses the latest technologies to create, delete, get by id and get all products, categories and tags of the e-commerce

# Aplication
 
## The initial build command is:  `npm i`
## The start command to seed data to your database so that you can test your routes will be `npm run seed`
## The start command to run you database will be `npm i start`
